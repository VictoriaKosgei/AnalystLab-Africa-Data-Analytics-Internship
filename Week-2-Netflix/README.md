# 🎬 AnalystLab Africa – Week 2: Netflix Movies & TV Shows Analysis

## 📌 Project Overview

This project was completed as part of the **AnalystLab Africa Data Analytics Internship – Week 2**.

The project focuses on cleaning, exploring, and analyzing the **Netflix Movies and TV Shows dataset** to identify trends in Netflix's content library, including content types, release years, ratings, countries, and genres.

The analysis was performed using **Python and Jupyter Notebook**, followed by the development of an interactive **Power BI dashboard**.

---

## 🎯 Project Objectives

* Clean and prepare the Netflix dataset for analysis.
* Explore the structure and characteristics of Netflix's content library.
* Analyze Movies vs. TV Shows.
* Examine Netflix content by release year.
* Identify popular genres.
* Analyze content by country and rating.
* Create visualizations to communicate key findings.
* Build an interactive Power BI dashboard.

---

The dataset contains information about Netflix Movies and TV Shows.

## 🧹 Data Cleaning

The dataset was inspected for missing values, incorrect data types, and inconsistencies.

Key cleaning activities included:

* Examining missing values.
* Handling missing and inconsistent data.
* Cleaning the `date_added` field.
* Correcting the `release_year` field.
* Checking data types.
* Preparing the cleaned dataset for analysis and visualization.

The final cleaned dataset contains **8,807 rows and 12 columns**.

---

## 🔎 Exploratory Data Analysis

The analysis explored several aspects of Netflix's content library, including:

### 🎥 Content Type

The dataset contains:

* **Movies:** 6,131
* **TV Shows:** 2,676

Movies therefore make up the larger share of the Netflix catalog.

### 📅 Release Year

The analysis examined how Netflix content is distributed across release years and highlighted the growth of newer content in the dataset.

### 🎭 Genres

The `listed_in` column was analyzed to identify the most common genres and categories available on Netflix.

### ⭐ Ratings

Content was analyzed according to its Netflix rating categories.

### 🌍 Countries

The analysis also examined the geographic distribution of Netflix content by country.

## 📈 Visualizations

The project included exploratory visualizations and an interactive Power BI dashboard featuring:

* Netflix content by type
* Content distribution by release year
* Top genres
* Content by rating

* Interactive filters/slicers for exploring the dataset

---

## 💡 Key Insights

* Movies represent the majority of titles in the dataset.
* Netflix's catalog contains a large variety of international content.
* Dramas, international movies, and comedies are among the most prominent content categories.
* The dataset is heavily concentrated around more recent release years.
* Netflix's content library shows significant diversity across countries, genres, and ratings.
